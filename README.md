# LinkVault Web Preview

Prototipo PWA estático para probar la interfaz desde Android o escritorio.

## Publicación
Sube el contenido de esta carpeta a un hosting estático HTTPS. Una vez publicada, abre la URL en Chrome para Android y usa el menú ⋮ > Instalar app / Añadir a pantalla de inicio.

## Funciones
- Diseño adaptable con efecto de vidrio y temas oscuro/claro.
- Navegación Inicio, Descargas, Seguridad y Ajustes.
- Analizador heurístico local de URL.
- Acción de apertura de enlaces directos para descarga mediante el navegador.
- Service worker y caché básica.

## Límites de seguridad y funcionalidad
- No consulta fuentes externas de reputación o malware.
- No garantiza que un enlace sea seguro.
- No descarga ni extrae medios desde redes sociales.
- El botón de descarga deja que el navegador gestione el enlace; la descarga depende del servidor.
- No envíes enlaces privados a servicios externos sin consentimiento.
- No se incluyen anuncios ni SDK de publicidad.

Es un prototipo de interfaz web, no una APK Android nativa.
